# Abrechnung als festgeschriebenes Dokument

Eine Abrechnung ist kein Filter über Reisen, sondern ein eigenes Dokument. Beim Einreichen werden die enthaltenen Reisen gesperrt und der Export unveränderbar gespeichert; eine Reise kann nur in einer Abrechnung stehen. Das verhindert doppelte Erstattung und erfüllt die GoBD-Anforderung an Unveränderbarkeit. Korrekturen laufen über eine protokollierte Entsperrung, die eine neue Version des Exports erzeugt, statt den alten zu überschreiben.
